# EDHOME Stable 0.8.0.14 — zmiany względem Stable 0.7.4.36

Źródło funkcjonalne: `beta` commit `bb5e4edcb67e92369094c54f149718aa221a9d9d`.
Promocja do Stable zatwierdzona przez Edwina 06.10.2026.

## Najważniejsze zmiany

- **Projekty:** hierarchia projektów/podprojektów, zależności, planowanie i dostępność.
- **Profile użytkowników:** lokalne profile, PIN-y i powiązanie danych z użytkownikiem.
- **PayCheck:** miesięczny plan budżetu i porównanie z potwierdzonymi wydatkami.
- **Kopia danych:** paczka ZIP z danymi oraz oryginalnymi mediami magazynu.
- **Magazyn:** dalsza stabilizacja galerii, szybkiego dodawania, miejsc, QR/NFC i synchronizacji Android ↔ Desktop.
- **SUPLA Cloud:** bezpieczny fundament tylko do odczytu kanałów/urządzeń; token w Android Keystore.
- **Nawigacja/UI:** poprawki stosu ekranów, dialogów, przewijania i spójności interfejsu.

## Stable

- Nazwa: **EDHOME**.
- Pakiet: `com.edwinkarolczyk.edhome`.
- Wersja: `0.8.0.14`, `versionCode 206`.
- Stable zachowuje PIN i ten sam trwały certyfikat podpisu.
- Stable ma LAN/Desktop, banki, NFC/QR, Projekty i SUPLA read-only.
- Stable nie zawiera beta-only bezpośredniego instalatora APK.
- Przed aktualizacją wykonaj kopię danych.
- Skrót zmian jest dostępny w **Aktualizacje → Co nowego**.
