# EDHOME 3D artwork — signed Beta APK

Place `EDHOME_AI_3D_100.zip` in this directory (exact filename). It must contain `manifest.json` and `icons/*.webp` (100 actual 192×192 icons). The CI validation checks their hashes and only publishes a complete bundle; the Android app installs the bundled pack automatically in the background. Import from the app's settings is an **optional** way to replace the pack, not a requirement to use EDHOME.

Never put user photographs, private data or signing keys here.
